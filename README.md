# UFFNV STORE & STREET FORUM (uffnv.ru)

Веб-платформа стритвир-бренда одежды, мерча и закрытого комьюнити-форума художников уличной волны.

---

## ⚡ Разблокированная версия (Production Ready)
* Все разделы интернет-магазина разблокированы и доступны:
  * `/pages/catalog.php` — Полный каталог товаров с фильтрами, сортировкой и категориями
  * `/pages/cart.php` — Корзина покупок с динамическим пересчетом
  * `/pages/checkout.php` — Оформление заказов с маской телефона и выбором оплаты
  * `/pages/delivery.php` — Условия доставки и самовывоза
  * `/pages/about.php` — История и манифест бренда UFFNV
  * `/pages/contacts.php` — Контакты и каналы связи
  * `/pages/topics_list.php` — Стрит-форум комьюнити

## 🛡️ Безопасность и конфиденциальность (152-ФЗ, ЗоЗПП РФ)
1. **Изоляция конфигурации базы данных:**
   * Боевые учетные данные вынесены в `config/db.local.php` (файл добавлен в `.gitignore` и защищен веб-сервером).
   * Для развертывания используется шаблон `config/db.example.php`.
   * Конфиг автоматически проверяет локальный файл -> переменные окружения (`DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`) -> безопасные значения разработки.
   * Исключен вывод системных трейсов и путей сервера наружу при сбое базы данных.
2. **Защита персональных данных (152-ФЗ) и защита потребителей (ЗоЗПП):**
   * Создана официальная Политика обработки персональных данных: `/pages/privacy.php`.
   * Создано Пользовательское соглашение и Публичная оферта с условиями возврата товара в течение 7 дней (ст. 26.1 ЗоЗПП): `/pages/terms.php`.
   * Форма регистрации (`pages/register.php`) дополнена активным чекбоксом 152-ФЗ и раздельным согласием на рекламные рассылки (38-ФЗ).
   * Форма оформления заказа (`pages/checkout.php`) снабжена обязательным юридическим акцептом оферты и согласия на обработку ПДн.
   * Внедрен интерактивный Cookie-баннер с фиксацией согласия в `localStorage`.
3. **Безопасность веб-сервера (.htaccess):**
   * Запрещен листинг директорий (`Options -Indexes`).
   * Запрещен прямой вызов служебных файлов (`db.php`, `db.local.php`, `*.sql`, `*.log`, `.env*`, архивов `*.zip`).
   * Добавлены защитные заголовки: `X-Content-Type-Options: nosniff`, `X-Frame-Options: SAMEORIGIN`, `X-XSS-Protection: 1; mode=block`, `Referrer-Policy: strict-origin-when-cross-origin`.

## 🚀 Быстрый старт
1. Клонирование репозитория:
   ```bash
   git clone https://github.com/uffnv/uffnv.git
   cd uffnv
   ```
2. Настройка подключения:
   ```bash
   cp config/db.example.php config/db.local.php
   ```
   Укажите локальные реквизиты MySQL.
3. Импортируйте базу данных форума и магазина в вашу СУБД.
4. Разверните на веб-сервере (Apache/Nginx) с PHP 8.1+ и PDO MySQL.
